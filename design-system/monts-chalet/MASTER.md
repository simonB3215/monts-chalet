## Component Specs

Implemented in `src/styles.css` (`@layer components`).

- **Buttons** `.btn`: min-height 48px (44px for `.btn-sm`), radius 8px, weight 700, colour transition 200ms, `cursor: pointer`.
  `.btn-primary` ember on white text (CTA only) · `.btn-secondary` 2px fir outline · `.btn-light` white, on photos.
  Hover changes colour only: no scale or translate, so nothing shifts.
- **Links** `.link`: fir text, ember underline 2px; standalone links are 44px tall.
- **Cards** `.card`: white, radius 12px, 1px `line` border, `shadow-sm`. Not clickable, so no hover lift.
- **Inputs** `.input`: min-height 48px, 16px text (no iOS zoom), visible label above, 1px `#8A8177` border, focus outline 3px fir. Errors: 2px `#B42318` border + text message linked with `aria-describedby`.
- **Lightbox**: native `<dialog>` (focus trap, Escape), 48px round buttons, caption + position.
- **Markers** `.marker`: dashed ember box in monospace for owner to-dos (`[DATES DE SAISON À DÉFINIR] / [SEASON DATES TO BE DEFINED]`, `[AÑADIR RESEÑAS REALES]`).
- **Icons**: Lucide (`lucide-static`), inline SVG, 1.5px stroke, `aria-hidden`. One set only.

## Style Guidelines

**Style:** Nature Distilled

**Keywords:** muted earthy tones, wood, stone, sand, terracotta, warmth, organic materials

**Key Effects:** natural ease-out easing, soft shadows, photography first. Texture overlays, grain and parallax from
the style record are **not** used: the photos already carry the wood and stone texture, and the brief asks for calm motion.

### Page Pattern

**Pattern Name:** Hero + Testimonials + CTA

- **CTA Placement:** hero + sticky. "Check availability / Voir les disponibilités" is in the fixed header from 640px and in a fixed bottom bar below 640px, on every page.
- **Section Order (home):** Hero > quick facts > the chalet > gallery preview > winter / summer > rates + CTA > reviews (placeholder) > map + contact.
- **Social proof:** real reviews only, added in `site.config.mjs`. Until then the section shows `[AÑADIR RESEÑAS REALES]`. Verifiable facts (capacity, location, distance to slopes) carry the trust role.

## Motion

**Scroll Reveal** (Subtle) — opacity 0→1 and 12px upward, 350ms, ease-out, once.

- Implemented with `IntersectionObserver` + CSS instead of GSAP: same effect, no library to download.
- Applied by JavaScript only to elements that start below the fold, so content is visible without JS and never flashes.
- Disabled entirely under `prefers-reduced-motion: reduce`; smooth scrolling too.
- Photo hover: scale 1.03 inside a clipped frame over 500ms (no layout shift), removed under reduced motion.

## Anti-Patterns (Do NOT Use)

- ❌ Poor photos
- ❌ Complex booking
- ❌ Invented reviews, ratings, surface areas or equipment (project rule)
- ❌ Purple or neon gradients, abrupt animation (project rule)

### Additional Forbidden Patterns

- ❌ **Emojis as icons** — Use SVG icons (Lucide)
- ❌ **Missing cursor:pointer** — All clickable elements must have cursor:pointer
- ❌ **Layout-shifting hovers** — Avoid scale transforms that shift layout
- ❌ **Low contrast text** — Maintain 4.5:1 minimum contrast ratio
- ❌ **Instant state changes** — Always use transitions (150-300ms)
- ❌ **Invisible focus states** — Focus states must be visible for a11y
